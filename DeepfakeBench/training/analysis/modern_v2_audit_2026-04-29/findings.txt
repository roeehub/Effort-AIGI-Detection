------------------------------------------------------------------------------

 -> kept: real=281  fake=367  (matches yaml: 281r / 367f)

Brief described an explicit ~96^2 pixel and a sharpness-band gate, but
the actual current filter uses neither — it gates on face_area_ratio
(>=0.10) and discrete tags (pose_extreme, no_face, capture_mode).
The relaxation is therefore designed against the *actual* gates.

RELAXED (modern_v2_relaxed) FILTER — chosen thresholds
------------------------------------------------------------------------------
clip_capture_mode not in {webcam, screen}     # capture-mode preserved
AND (face_area_ratio >= 0.0625                # = 64^2 / 256^2
     OR face_pixel_area >= 4096)              # = 64^2 hard floor
AND not is_no_face                            # moot in lockbox (0 hits)
# is_pose_extreme gate REMOVED (relaxed)
 -> kept: real=308  fake=390
    new real frames vs current: 27 (mostly dor_shkedi pose-extreme + low face_area)
    new fake frames vs current: 23

Rationale for the chosen relaxations:
  * 0.0625 face_area_ratio corresponds to a 64x64 face in a 256x256 crop,
    which is the explicit floor the brief asked for. Within the non-
    webcam/screen real population this only adds 7 frames (pixel-area-only
    floor adds 0 incremental beyond the ratio), so the geometry relax is
    very modest — the bulk of new frames come from the pose-extreme gate.
  * Sharpness band: brief asked for p25-p95 of dev_real. There is no
    'dev' split in this parquet (only lockbox). The lockbox-real
    non-webcam/screen sharpness p25=181, p95=763. The current filter has
    no sharpness gate at all, so 'relaxing' an already-absent gate is a
    no-op. We document this and proceed; if a future iteration adds a
    sharpness gate we should re-run this audit.
  * Pose-extreme gate is the load-bearing relaxation: it currently drops
    27 dor_shkedi non-webcam/normal_photo frames that look like real
    Teams captures with off-axis head pose — a typical deployment
    condition that should NOT be excluded from a lockbox real pool.
