What changed vs prior packets:

- **From-scratch** (`load_base_checkpoint: false`) — first FROM_SCRATCH packet since E2/E2b/E3. Tests whether shortcut acquisition can be PREVENTED rather than UNLEARNED. Justified empirically by Job 7 (today's PD vs P1 head-to-head FACTS doc): no FT-child strictly dominates its FT-base; both arms trade invariances at calibrated τ.

- **Quality_enhancement routing fix applied** — first R13 packet trained on the corrected routing (memory `project_quality_enhancement_routing_2026-05-05.md`). ~5,120 deeplive_enhanced frames stop being mislabeled.
- **face_scale_jitter@0.50** baseline aug — P14 winner on trainer composite, kept consistent across all 3 slots.
- **No GroupDRO**, **no anchor_aware**, **no codec aug**, **no data-axis lever**, **no is_webcam axis** — explicit "what we're NOT doing" list documented in the yaml headers; each exclusion has a citation to a refuting memory or finding.

### In-session opinion (read second, with skepticism)

The agent who proposed this packet staked a position in the cold-start simulation that pair_rank's tail-collapse is a calibration-shifting failure mode, refutable by Platt scaling. **This was REFUTED today** by Job 5 (joint τ-sweep): F1 ∩ F4 ∩ F5 overlap region is empty for P1 BUNDLE_step500 because Roy_D's score distribution overlaps lockbox fakes at the per-frame level — no monotone rescaling separates them. The fix has to be representational. P2 SCRATCH is the test of "can the representation be shaped to avoid this failure mode by training from step 0 with the right losses."

The retraction was done before launch — the proposal that landed addresses the per-frame overlap problem by including `color_b_dev` in corr_penalty (the Roy_D-mechanism axis) and by training from scratch (so the representation cannot inherit P8A's "happy accident" Roy_D feature, which would only be unwound by FT).

A reviewer should weight the OPINION subsection of this retro with the calibration: this packet's design encodes a SPECIFIC mechanism claim (Roy_D regression = unwinding of an identity-specific learned color_b_dev signal). If the canary readouts on Slot A or C show Roy_D regression even from scratch, the mechanism claim is partially refuted and the next packet pivots. If the canary stays clean on Roy_D for Slot A but not Slot C, pair_rank is identified as the lever class that produces the regression independent of FT chain.
