## 1. Method

For each ckpt × sub_cohort:

1. Load L11 CLS features (512-d) and labels from the triptych. Sub_cohort ∈ {full, chronic_6, non_chronic}.
2. Fit `sklearn.linear_model.LogisticRegression(C=1.0, max_iter=2000)` on (features → label∈{0,1}). Record 5-fold CV AUC. Extract `w_rf = .coef_[0]`. Normalize to unit length.
3. For each of the 6 IQ axes (`lap_var, min_dim, color_a_dev, color_b_dev, saturation_mean, luma_mean`), z-score axis values; fit `LinearRegression` (features → axis_value); extract `w_axis = .coef_`; normalize to unit length.
4. Per-axis angle (deg): `angle = arccos(|<w_rf, w_axis>|) * 180/π`. Unsigned because the axis direction is sign-agnostic.
5. IQ PC1 angle: stack the 6 `w_axis` vectors as rows in a 6×512 matrix; take the first right-singular-vector of that matrix; normalize to unit length; compute unsigned angle vs `w_rf`.

**Random-orthogonality baseline in 512-d space**: two random unit vectors have expected cos² ≈ 1/512 ≈ 0.0020, so expected angle ≈ **87.5°**. Angles in [86°, 90°] are within sampling noise of pure orthogonality at this feature dimensionality.

## 7. Caveats

- 512-d feature space → expected random-orthogonality angle ≈ 87.5°. Angles in [86°, 90°] are within sampling noise of pure orthogonality. The load-bearing comparison is whether an angle is materially below 87° (= non-random structure detected).
- Sub_cohort sample sizes vary: full=800, chronic_6=282, non_chronic=518. Per-cohort probe AUCs are 5-fold CV; small CV folds (e.g., chronic_6/5 ≈ 56 frames) inflate AUC variance.
- IQ atlas join is at the frame level via path matching; rows with null IQ values are dropped from the per-axis regression but retained for the real/fake probe (so n for the angle calculation matches n for the probe within each sub_cohort).
- The IQ PC1 is computed as the first right-singular-vector of the 6×512 axis-direction matrix; the variance captured by PC1 (the singular-value squared / sum) is not reported in the CSVs and is not part of this FACTS doc.
- The CLIP_FROZEN extraction used OpenCLIP B16 (datacomp_xl_s13b_b90k); the same backbone tag as the project's standard FT base. The forward pass extracted L11 CLS features after `visual.ln_post` (post-layernorm) and `visual.proj` (post-projection) to match the FT'd ckpts' caching convention.
- The 5-ckpt comparison was on the same 800-frame panel; the panel itself is not stratified by lockbox vs dev (the triptych was sampled in 2026-04-30 for embedding probes; identity composition is not balanced — see `JOB1_L11_DISTANCE_FACTS_2026-05-12.md` §8).
- This FACTS doc was authored post-stall from CSVs; the originating script `run_d2.py` is in the same folder and is the canonical reproducibility surface.
