# Effort / AIGI agent policy

- The primary training and evaluation code is under `DeepfakeBench/training/`.
- Read the nearest nested `AGENTS.md` before launching, moving, or cancelling
  training jobs.
- Project research workflows live in `.agents/skills/`; use the relevant skill
  for repository understanding, paper analysis, and experiment history.
- Durable project knowledge belongs to the `ml-training` vault domain. Agents
  may append inbox notes but must not directly rewrite canonical memory.
- Preserve large datasets, model artifacts, caches, and unrelated experiment
  outputs unless the user explicitly asks to modify or remove them.
