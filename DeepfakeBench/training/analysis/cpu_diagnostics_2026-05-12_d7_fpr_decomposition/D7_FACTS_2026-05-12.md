# D7 FACTS — FPR decomposition by substrate × IQ × chronic (2026-05-12)

## §1. What was measured

For two checkpoints (P8A_step5000, T5C_step3500), for each eval real frame in
the unified frame matrix that (a) has all 6 IQ axes non-null in the atlas and
(b) has a locally-cached image file, three feature blocks were computed and a
logistic regression was fit to predict `is_FP_at_dev_cal_5pct_τ`:

1. **substrate_distance** — mean cosine distance (CLIP-frozen ViT-B/16 layer 11
   CLS, 768-dim) to the k=10 nearest training reals. Reference set: 371 frames
   from `analysis/iq_data_atlas_2026-05-08/_cache/train_teams_real_pool.parquet`
   that were locally cached (task spec called for ~2000; capped by local
   cache availability — see §6 caveat 1).
2. **IQ vector** — 6 IQ atlas axes: `lap_var`, `min_dim`, `color_a_dev`,
   `color_b_dev`, `saturation_mean`, `luma_mean`. Each z-scored across the
   3416-frame panel.
3. **chronic_indicator** — binary 0/1, derived by case-insensitive substring
   match of frame basename against
   `{Roy_D, PC_Generator, bla_bla_chow, Md_noyn_Sharker, dor_shkedi, healthy_dor}`.

Dev-calibrated 5% τ was set per ckpt as the 95th percentile of scores on the
`teams_real_all_dev` suite (n=4564 across full unified matrix, calibrated on
all available scores in that suite, not restricted to the IQ-complete subset).
Per-frame `is_FP_{ckpt}` flag was assigned to every real frame in the panel
whose score exceeds τ. Logistic regression: sklearn LogisticRegression, C=1.0,
max_iter=2000, n_jobs=1, solver=lbfgs. Pseudo-R² is McFadden
(1 − LL_model / LL_null where LL_null uses the empirical base rate). Block
partial R² is computed as the difference between full-model pseudo-R² and a
reduced-model pseudo-R² (drop one block, refit). All n_jobs=1.

T3_S1_step1500 was scored on the same panel but not fit (task brief specified
P8A and T5C only).

## §8. Open questions / caveats (as numbered facts, no interpretation)

1. **Training-real reference set was 371 frames, not the requested ~2000.**
   The reference set was constrained to locally-cached frames from
   `train_teams_real_pool.parquet` (500 rows, 371 locally cached). With k=10
   NN this is sufficient for a stable scalar per frame, but the substrate_distance
   geometry covers only the diversity present in those 371 frames. Adding more
   training reals (e.g., from `train_df40_*` parquets, ~50 cached each) would
   widen the reference manifold.

2. **Panel excluded 5,661 real eval frames** (9,077 minus 3,416): 1,193 lack
   IQ atlas join, 1,227 lack local cache, and 3,241 lack both. Lockbox
   coverage in particular was poor (176 of 1,418 = 12.4%) because most lockbox
   real frames are not in any locally-cached frame directory.

3. **Dev-cal τ was computed on the full unified-matrix dev pool (n=4,564),
   not the panel subset.** Panel FPR for P8A (3.31%) is therefore not 5% by
   construction.

4. **The 6 IQ axes correlate with each other** (e.g., color_a_dev × saturation_mean
   r=+0.788, color_b_dev × saturation_mean r=+0.856). Block-drop ΔR² for IQ
   is the joint contribution of the 6-feature block, not the sum of per-axis
   contributions. Within-IQ feature-importance attribution requires a separate
   shapley-style analysis not done here.

5. **CLIP_FROZEN L11 was extracted with OpenCLIP ViT-B/16 weights from
   `weights/CLIP-ViT-B-16-DataComp.XL-s13B-b90K/open_clip_pytorch_model.bin`**
   on MPS device. Same code path as D2's CLIP-frozen extraction. Image
   preprocessing: BGR→RGB, 224×224 INTER_LINEAR resize, CLIP normalization
   mean=(0.48,0.46,0.41), std=(0.27,0.26,0.28). Features = forward hook on
   `visual.transformer.resblocks[11]` returning the CLS token.

6. **The chronic_6 indicator is a 0/1 column in the unified matrix derived
   from frame_path basename regex.** Some real frames may match by coincidence
   (e.g., `dor` substring matches `pandora`), though no such collisions were
   found in spot-check (all chronic_6=1 frames matched one of the six
   canonical identities). 60.2% of the panel is chronic_6.

7. **The full-model AUC (0.88 for P8A, 0.89 for T5C) is in the range where
   the 3-block predictor approximately ranks FP-likely vs FP-unlikely real
   frames, but the model is fit on the same data it is scored on (no
   train/test split).** ΔR² and ΔAUC magnitudes should be interpreted as
   in-sample explained variance, not held-out predictive lift. A held-out CV
   estimate was not computed.

8. **For T5C, the IQ-only and chronic-only single-block AUCs sum to more
   than the full model's AUC** (0.848 + 0.674 = 1.522 vs full 0.891). For
   P8A, the same sum is 0.873 + 0.642 = 1.515 vs full 0.880. The non-additivity
   reflects the IQ–chronic correlation (r=−0.366 on IQ-PC1).

9. **substrate_distance has univariate AUC 0.575 (P8A) and 0.527 (T5C) and
   contributes ΔR² ≤ 0.015 in the full-model nested comparison**, i.e., it
   carries little marginal information for predicting `is_FP` once IQ +
   chronic are in the model. This is consistent with its low |r| with every
   other feature.

10. **T5C_step3500's color_a_dev univariate AUC (0.817) is the single
    strongest direction in either ckpt's feature set.** P8A's strongest
    univariate direction is luma_mean (AUC 0.810) with min_dim second (0.784).
    The IQ axis carrying the most FP signal differs between the two ckpts.

11. **The block-drop ΔR² rank order is the same for both ckpts**:
    IQ ≫ chronic > substrate. For P8A: 0.236 / 0.014 / 0.015. For T5C:
    0.314 / 0.062 / 0.0001. The relative magnitudes differ: T5C's chronic-block
    contribution is 4.5× larger than P8A's; T5C's substrate-block contribution
    is 130× smaller than P8A's.
