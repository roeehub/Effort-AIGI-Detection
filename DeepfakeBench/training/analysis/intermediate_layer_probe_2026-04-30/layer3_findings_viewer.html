Plain-English Reading

The finding is not just "layer 3 has decent AUC." The important pattern is transfer: a classifier trained on dev features keeps working on lockbox at layer 3, then largely stops working at layers 6 and 11. That is exactly what a substrate-confounded representation looks like.

Critical Evaluation

What is genuinely strong
  • The direction is consistent across independent probes: small split transfer, scaled transfer, MLP capacity, and production-honest FPR.
  • The scaled LR result uses 839 lockbox frames, not only the small 87-frame lockbox slice.
  • The layer-11 failure is mechanically plausible: within-split AUC is high while dev -> lockbox transfer collapses.
What is weaker than the memo says
  • The original MLP script selects the best epoch by lockbox AUC, so the 92.9% rec@5% headline is optimistic.
  • The 180-frame production-honest set is all real; it measures false positives, not fake recall or calibrated deployment utility.
  • The original staged P17 YAML claimed a frozen backbone, but local gradient inspection showed SVD residual gradients in resblocks 0-3.
  • The original P17 schedule used non-trainer keys (total_steps, warmup_steps, save_steps), which would not launch as described.
  • visomaster_enhanced_macro_dev has n=0 in the per-method JSON, so the scorecard slice is incomplete.
What must be proven next
  • The trainer/ArcFace layer-3 head must reproduce the offline LR/MLP behavior under the actual training and scorecard path.
  • The P17 config must keep freeze_svd_residuals: true or use a true head-only optimizer before it tests the stated hypothesis.
  • The new head needs an untouched validation target for epoch and threshold selection.
  • The patch should be tightened to reset the captured hook value each forward and fail loudly if the hook does not fire.

Bottom line: this is a high-quality diagnostic and a good experiment direction. It is not yet a deployment finding. Treat the CPU result as a mechanistic hypothesis with unusually strong support, then demand clean holdout promotion.
